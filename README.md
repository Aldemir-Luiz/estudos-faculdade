# 🎓 Estudos de Graduação

Repositório dedicado ao armazenamento de exercícios, práticas laboratoriais e atividades desenvolvidas durante as disciplinas da graduação.

## 📁 Estrutura de Pastas
- `/seguranca-informacao`: Algoritmos criptográficos, análises e conceitos teóricos de segurança.
- `/banco-de-dados`: Scripts DDL/DML, consultas SQL e modelagem relacional.
- `/programacao-web`: Exercícios de frontend, lógica e manipulação de dados na web.
